A little about us

Big-hearted work
takes a good table.

Lantern & Loom is a fictional independent production studio designed as a hands-on test project. We believe a site can be simple, expressive, and still be easy to publish.

This project uses plain HTML, CSS, and JavaScript—no build system required. That makes it useful for learning how GitHub repositories and Cloudflare Pages deployments fit together.
